## 확정 근거와 검증

- 공식 Work 기록 `블루쉬프트 4인 등록 이미지 만들기`에서 사용자가 세 멤버의 최종 보드를 4K로 저장하도록 요청했고, 이어 “4K 최종본만 남기고”와 C 드라이브 사용자 폴더에 복사했으니 “이제 거기서 쓰도록”이라고 지정했습니다.
- 공식 Work 기록 `블루쉬프트 4인 캐릭터 보드 찾기`에서 사용자가 해당 폴더 위치를 직접 확인했습니다. 이 기록의 초기 잘못된 인물 매핑은 사용자의 정정 이후 기록을 기준으로 배제했습니다.
- 나미루 2장은 H 드라이브의 기존 얼굴 정본·체형 4K 파일과 SHA-256이 일치합니다.
- 5장 모두 실제 이미지를 열어 인물 표기·얼굴 특징·극화체 및 보드 구성을 확인했습니다.
- 이미지에 인쇄된 키 설정은 원본 그대로 보존한 표기이며, 별도의 최신 설정표나 실측 보증으로 해석하지 않습니다.
- 파일별 해상도·바이트 크기·SHA-256은 [manifest.json](manifest.json)에 기록했습니다.
